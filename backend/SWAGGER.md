# Swagger API Documentation

## Доступ к документации

После запуска приложения Swagger UI доступен по адресу:
- **Локально**: http://localhost:3000/api
- **Production**: http://your-domain/api

## Описание API

### Теги

#### 1. **app** - Общие эндпоинты приложения
Содержит базовые эндпоинты для проверки работоспособности сервера.

#### 2. **blackouts** - Операции с авариями
Управление данными об авариях электро-, водо- и теплоснабжения, а также информация о городах и зданиях.

**Эндпоинты:**
- `GET /blackouts/getAll` - Получить все аварии
- `GET /blackouts/cities` - Получить все города
- `GET /blackouts/cities/:id` - Получить город по ID
- `GET /blackouts/buildings` - Получить все здания с полной информацией

#### 3. **count-blackouts** - Статистика и аналитика по авариям
Предоставляет статистические данные по авариям.

**Эндпоинты:**
- `GET /count-blackouts/types` - Получить количество аварий по типам

## Модели данных

### Blackout (Авария)
- `id` - Уникальный идентификатор аварии
- `startDate` - Дата и время начала аварии
- `endDate` - Дата и время окончания аварии (опционально)
- `predictedEndDate` - Прогнозируемая дата окончания (опционально)
- `description` - Описание аварии (опционально)
- `type` - Тип аварии: electricity, cold_water, hot_water, heat
- `initiatorName` - Имя инициатора аварии (опционально)
- `source` - Источник информации (опционально)

### City (Город)
- `id` - Уникальный идентификатор города
- `name` - Название города

### Building (Здание)
- `id` - Уникальный идентификатор здания
- `streetId` - ID улицы
- `number` - Номер дома
- `districtId` - ID района
- `folkDistrictId` - ID микрорайона
- `bigFolkDistrictId` - ID большого микрорайона
- `type` - Тип здания
- `cityId` - ID города
- `latitude` - Широта (опционально)
- `longitude` - Долгота (опционально)
- `isFake` - Является ли здание фиктивным

### BlackoutTypesCount (Статистика по типам аварий)
- `electricity` - Количество аварий электроснабжения
- `cold_water` - Количество аварий холодного водоснабжения
- `hot_water` - Количество аварий горячего водоснабжения
- `heat` - Количество аварий теплоснабжения


1. Откройте браузер и перейдите по адресу http://localhost:3000/api

2. В интерфейсе Swagger UI вы можете:
   - Просмотреть все доступные эндпоинты
   - Ознакомиться с моделями данных
   - Протестировать API напрямую из браузера
   - Скачать OpenAPI спецификацию в формате JSON


## Дополнительные возможности

- Все entity и DTO полностью задокументированы с помощью декораторов `@ApiProperty`
- Каждый эндпоинт содержит подробное описание и примеры ответов
- Swagger UI поддерживает интерактивное тестирование API
- OpenAPI спецификация может быть использована для генерации клиентского кода
